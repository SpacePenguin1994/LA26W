04 · 从混音实验，走进线性空间

为什么整段声音，也可以是向量？

刚才的消元里，等号两边有时是人声，有时是旋律。它们并不是一个数，却仍然能相加、数乘、抵消。线性空间研究的，就是这些运算共同遵守的规律。

01

先把声音看成一条完整波形

固定同一段时间 0 ≤ t ≤ T，用 f(t) 表示时刻 t 的振幅。

向量加法 · 叠加
(f + g)(t) = f(t) + g(t)

把两段声音对齐，在每个时刻将振幅相加。比如，人声加旋律得到混音。

数乘 · 缩放振幅
(αf)(t) = αf(t)

把每个时刻的振幅都乘同一个实数。0.5f 把振幅减半；−f 把波形上下翻转。

负数倍是波形反相，并非倒放；乘以 2 指振幅变成两倍，并不表示主观听感的响度恰好变成两倍。

02

实线性空间：一个集合，两种运算，八条规律

其中的元素叫作“向量”。向量可以是数列、函数、矩阵，也可以是我们正在研究的声音波形。

给定一个非空集合 V，在其中定义加法和实数数乘。首先要求运算封闭：对任意 x, y ∈ V 和 α ∈ ℝ，

x + y ∈ V，  αx ∈ V。

也就是说，运算结果仍在这个集合里。若再满足下面八条规律，就称 V 为实线性空间，也叫实向量空间。

下面 x、y、z 是 V 中任意元素，α、β 是任意实数。右侧的声音解释都指对齐后的理想波形。

  1. 加法交换律

    x + y = y + x

    两段对齐的波形相加时，交换相加顺序，结果不变。

  2. 加法结合律

    (x + y) + z = x + (y + z)

    三条音轨分组叠加，最终得到同一条波形。

  3. 存在零向量

    存在 0 ∈ V，使 x + 0 = x

    全程振幅为 0 的静音就是零向量；加入静音不改变原声。

  4. 每个向量都有相反向量

    每个 x 都有 −x ∈ V，使 x + (−x) = 0

    原波形与它的反相波形逐点相加，恰好抵消成静音。

  5. 数乘单位律

    1x = x

    振幅乘以 1，仍是原来的声音。

  6. 数乘结合律

    α(βx) = (αβ)x

    先缩小到一半，再放大两倍，振幅回到原样。

  7. 数乘对向量加法的分配律

    α(x + y) = αx + αy

    先混音再缩放，等于把各条音轨同样缩放后再混音。

  8. 数乘对实数加法的分配律

    (α + β)x = αx + βx

    0.3 倍人声加 0.7 倍同一人声，正好得到原人声。

声音为什么满足这些要求？

取 V = C([0, T], ℝ)，即这段时间内所有实值连续波形的集合。两条连续波形相加、乘实数后仍连续，所以运算封闭；静音和反相波形也都在其中。其余等式在每个时刻都化为实数的运算规律，因此对整条波形成立。

这里使用不限制振幅大小的理想模型。若强行要求振幅始终在 −1 到 1 之间，放大后就可能超出范围，这样的集合对数乘不封闭。

03

两条音轨，能组成一个怎样的空间？

只用固定的人声 v 和旋律 m，把所有可能的混音收集起来。

由 v、m 张成的空间
W = span{v, m}
= {av + bm : a, b ∈ ℝ}

它是声音空间的一个子空间：其中的元素是声音，并且相加、数乘后仍留在 W 中。

为什么仍留在里面？

若 u = av + bm，w = cv + dm，那么

u + w = (a + c)v + (b + d)m
ku = (ka)v + (kb)m。

结果仍是 v、m 的线性组合。取 a = b = 0，还能得到静音。

你现在设置的两条混音
u = v + mw = v + 2m

右图画的是它们的混合系数 (a, b)，不是声音的时间—振幅波形。一个点对应一整段混音。

如果 v、m 线性无关，也就是 αv + βm = 0 只能在 α = β = 0 时成立，那么每段混音的系数唯一。此时 {v, m} 是 W 的一组基，W 的维数为 2，(a, b) 就是声音 av + bm 在这组基下的坐标。

“二维”表示只需两个独立的系数来描述 W 中的声音，不是每段声音只有两个采样值。滑杆的 −3 到 3 只是展示范围；完整的 W 允许任意实系数。

04

既然能写成坐标，为什么还要讲线性空间？

坐标帮助我们计算，线性空间帮助我们识别不同对象背后的同一套结构。

电脑怎样保存声音

N 个采样值：ℝᴺ

f ↦ (f(t₁), …, f(tN))

固定采样时刻后，把振幅排成一列。本网页的数字音频确实在 ℝᴺ 中做运算；混音就是对应位置相加、数乘。

这个实验怎样描述混音

两个混音系数：ℝ²

av + bm ↔ (a, b)

当 v、m 线性无关时，只需两个数描述它们张成的空间。换一组基，同一段声音的坐标可能改变，声音本身不变。

数学怎样描述连续波形

一个函数：C([0, T], ℝ)

t ↦ f(t)

这里保留每个时刻的振幅。有限个采样值无法唯一确定任意连续波形；整个连续函数空间也无法由固定有限个基波形张成。

把共同规律提炼出来，才可以把同一个方法用于不同对象。

有限维实线性空间选好基后，都可以用 ℝⁿ 的坐标来计算。但在选坐标之前，我们就能研究声音、矩阵、多项式的相加与数乘；对于整个连续函数空间，还需要容纳无限维情形。线性空间让我们把这些情况放在同一套理论中讨论。

05

回看消元：我们一直在使用这些规律

以“可逆混音”预设 u = v + m、w = v + 2m 为例：

w − u = (v + 2m) − (v + m) = m
2u − w = 2(v + m) − (v + 2m) = v

这里用到分配律、结合律和相反向量的抵消。它们对整段声音成立，所以消元能直接找回音轨。线性代数的方法能处理声音，正是因为声音的这些运算具有线性空间的结构。
